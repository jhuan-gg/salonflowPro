# Salonflow Pro

English / Português

---

## Overview

Salonflow Pro is a management application for beauty salons: scheduling, clients, attendants and services. It provides an admin UI to create and manage appointments, clients, attendants, services and view history and receipts.

Key features

- Appointment scheduling and completion flow
- Client, attendant and service management
- History and receipts
- Responsive UI built with component primitives

Tech stack

- Frontend: Vite + React + TypeScript
- Styling: Tailwind CSS
- State & data fetching: TanStack Query
- Backend / Auth / Database: Supabase

Getting started (English)

1. Install dependencies:

```bash
npm install
```

2. Create a `.env` file in the project root with the required Supabase variables (see Environment below).

3. Start dev server:

```bash
npm run dev
```

4. Open your browser at `http://localhost:5173`.

Useful scripts (from `package.json`)

- `npm run dev` — start development server
- `npm run build` — build for production
- `npm run build:dev` — build in development mode
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
- `npm run test` — run Vitest tests

Environment

Required environment variables (example names used by this repo):

- `VITE_SUPABASE_URL` — Supabase project URL
- `VITE_SUPABASE_PUBLISHABLE_KEY` — Supabase anon/publishable key

These variables are referenced in [src/integrations/supabase/client.ts](src/integrations/supabase/client.ts#L1-L30).

Project structure (high level)

- `src/` — application source
- `src/components/` — UI components and domain components
- `src/pages/` — route pages (Agenda, Atendentes, Clientes, etc.)
- `src/integrations/supabase/` — autogenerated Supabase client and types
- `supabase/migrations/` — database migration SQL

Notes

- The repository uses `@supabase/supabase-js` v2 and reads env vars via `import.meta.env`.
- LocalStorage is used by the Supabase client for session persistence.

## Visão geral

Salonflow Pro é uma aplicação de gestão para salões de beleza: agendamento, clientes, atendentes e serviços. Fornece uma interface administrativa para criar e gerenciar agendamentos, clientes, atendentes, serviços e consultar histórico e recibos.

Principais funcionalidades

- Fluxo de agendamento e conclusão de atendimento
- Gerenciamento de clientes, atendentes e serviços
- Histórico e recibos
- Interface responsiva construída com componentes reutilizáveis

Stack tecnológico

- Frontend: Vite + React + TypeScript
- Estilização: Tailwind CSS
- Estado e fetch: TanStack Query
- Backend / Autenticação / Banco: Supabase

4. Abra o navegador em `http://localhost:5173`.
